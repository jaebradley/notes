# [Don't be a meat proxy](https://gruhn.me/blog/2026-08-03/)
* "Claude said: [huge response]"
  * Doesn't add value - anybody can talk to Claude/some LLM
* Reading AI output takes extra effort because it is verbose and _looks plausible_ even if it contains nonsense
* Use AI prompts, but don't just relay the output
  * Read it, understand it, validate it, and then write a response using your own words
