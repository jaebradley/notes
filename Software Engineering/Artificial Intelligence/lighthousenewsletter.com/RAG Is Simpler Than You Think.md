# [RAG Is Simpler Than You Think](https://www./p/rag-is-simpler-than-you-think)

## Potential Feature Requirements
* Real-time updates via news or social media favor approaches that support easy re-indexing
* Stable data corpus (monthly or quarterly updates) can mean sensible pre-embedding
* 10%+ daily corpus churn means avoiding full pre-embeddings
* Keyword-heavy queries should start with full-text search while conversational queries benefit from embeddings

## Agentic Query Rewriting
* This approach uses an LLM to transform user queries into keyword searches
* Idea is that most "search" problems boil down to building the optimal query (the most accurate keywords, etc)
