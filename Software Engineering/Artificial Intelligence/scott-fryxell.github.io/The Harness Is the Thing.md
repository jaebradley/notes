# [The Harness Is the Thing](https://scott-fryxell.github.io/blog/the-harness-is-the-thing/)
* Author found that a single prompt that plans, executes, and then critiques itself tends to get confused when attempting to accomplish its objectives
  * Author instead isolates roles like exploration, plan formalization, work execution, critiquing, and promoting
* Author also mixes model types across these different roles
  * For example, the frontier models are mostly used for palnning and critiquing
