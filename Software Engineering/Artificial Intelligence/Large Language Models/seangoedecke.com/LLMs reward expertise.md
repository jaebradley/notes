# [LLMs reward expertise](https://www.seangoedecke.com/llms-reward-expertise/)
* Because LLMs can help identify solutions when an individual has a knowledge gap (for example, one can't write CSS) many people don't think there is skill involved in working with LLMs
  * Everybody is using the same models, so both skilled prompters and unskilled prompters are getting the same results
* Author argues that the most important skill in prompting is expertise in the domain you're prompting for
* Author uses [Terence Tao's ChatGPT conversation](https://chatgpt.com/share/6a5fdc7a-d6f8-83e8-bbea-8deb42cfed56) as an example of how Tao's mathematical expertise drives the conversation with ChatGPT
  * Tao's messages are short and direct
  * Tao's messages are specific - "does X work here" or "if A and B, why C?"
  * Tao pushes back when the model's responses look incorrect
    * Tao doesn't directly contradict the model, but says things like "this looks more complex than I was hoping for"
  * Tao makes several leaps and suggestions himself and almost never takes the model's advice about where to go next
* If you have your own sense of what a good solution might look like, you can say things like "no, I think it could be simpler here", or "but don't we already do XYZ?", or "can we express this problem in these familiar terms?"

## [HackerNews Discussion](https://news.ycombinator.com/item?id=49161518)
* [Commenter ran an experiment](https://news.ycombinator.com/item?id=49163331) with a non-technical friend where this friend was trying to prompt an LLM to build a single page web application
  * Non-technical friend spent 90 minutes trying to build this web application before stopping
  * Non-technical friend didn't have the vocabulary to ask the LLM to write code
* ["People who (carefully) use it as an extension of their own mind and senses will very likely thrive, and those who use it as a replacement for their minds and their senses will struggle."](https://news.ycombinator.com/item?id=49162323)
